# 🔐 EnDeCryptCore

EnDeCryptCore is a secure JavaFX desktop application designed for text and file encryption/decryption using Caesar and Vigenère cryptographic algorithms. The system features SHA-256 password authentication, per-user persistent history, drag-and-drop file processing, customizable encryption parameters, and a scalable object-oriented architecture.

## Features

- Text encryption and decryption
- File encryption and decryption
- Caesar Cipher implementation
- Vigenère Cipher implementation
- SHA-256 password hashing
- User authentication and session management
- Per-user persistent history tracking
- Drag-and-drop text file support
- Custom Caesar shift values
- Custom Vigenère keys
- Random key generation
- Save encrypted/decrypted output
- Exception handling and input validation
- JavaFX graphical user interface

## Technologies

- Java

- Object-Oriented Programming (OOP)
- File I/O
- Java Collections Framework
